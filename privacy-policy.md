# Политика конфиденциальности QueueWatch

Дата вступления в силу: 14 сентября 2026 г.

QueueWatch — приложение для отслеживания положения транспортного средства в электронной очереди. Настоящая Политика конфиденциальности объясняет, какие данные используются приложением и для каких целей.

## Источник информации и неофициальный статус

Источником сведений об электронной очереди является официальная система электронной очереди РУП «Белтаможсервис»: https://belarusborder.by/

Официальный сайт Государственного пограничного комитета Республики Беларусь: https://gpk.gov.by/

QueueWatch — независимое неофициальное приложение. Разработчик QueueWatch не представляет РУП «Белтаможсервис», Государственный пограничный комитет или другие государственные органы Республики Беларусь. Сведения предоставляются исключительно в информационных целях и могут поступать с задержкой. Перед поездкой необходимо проверять актуальные сведения в официальных источниках.

## Какие данные обрабатывает QueueWatch

Для выполнения основной функции приложения пользователь самостоятельно вводит регистрационный номер транспортного средства. Этот номер используется для поиска соответствующей записи в электронной очереди и отображения пользователю актуальной информации о положении транспортного средства.

QueueWatch не требует создания пользовательского аккаунта и не запрашивает имя, адрес электронной почты, номер телефона, точное местоположение, контакты, фотографии, аудиозаписи или иные подобные персональные данные для работы основной функции.

## Цель обработки данных

Регистрационный номер транспортного средства используется исключительно для предоставления функций QueueWatch, связанных с поиском и отслеживанием транспортного средства в электронной очереди.

## Передача и продажа данных

QueueWatch не продаёт пользовательские данные и не использует их для рекламы или маркетинга.

Для выполнения основной функции приложение обращается через интернет к сервисам, необходимым для получения сведений электронной очереди. Данные не предоставляются рекламным сетям и не используются для создания рекламного профиля пользователя.

## Безопасность передачи данных

### Экспериментальное приложение QueueWatch Forecast

В отдельном приложении QueueWatch Forecast прогнозы, позиции в очереди, пункт пропуска, тип транспорта, время наблюдения и подтверждённого вызова передаются в общую базу Supabase для проверки точности. Записи связываются случайным идентификатором установки и случайным идентификатором сессии. Регистрационный номер автомобиля, Android ID, MAC-адрес и данные аккаунта в эти записи не включаются. Отправка выполняется по HTTPS; при отсутствии связи ограниченная локальная очередь сохраняет записи для повторной отправки.

Эта функция действует только в экспериментальном QueueWatch Forecast. Обычный QueueWatch такую телеметрию не отправляет. Очистка данных или удаление Forecast удаляет локальный идентификатор и локальную очередь; уже принятые сервером записи автоматически при этом не удаляются.

При сетевом обмене приложение использует защищённые соединения HTTPS там, где они поддерживаются используемыми сервисами.

## Хранение и удаление

QueueWatch не создаёт пользовательских аккаунтов. Данные, необходимые для работы функций приложения, обрабатываются в объёме, необходимом для предоставления этих функций. Если архитектура или порядок хранения данных QueueWatch изменятся, настоящая Политика конфиденциальности будет соответствующим образом обновлена.

## Дети

QueueWatch не предназначен специально для детей и не разработан для целенаправленного сбора персональных данных детей.

## Изменения политики

Политика конфиденциальности может обновляться при изменении функций приложения, способов обработки данных или применимых требований. Актуальная версия публикуется на этой странице.
